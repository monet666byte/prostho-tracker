# เปิด "เข้าสู่ระบบด้วย Google" (ทำครั้งเดียว · ~30–45 นาที)

โค้ดฝั่งแอปพร้อมแล้ว (14 ก.ย. 69) ที่เหลือคือตั้งค่าในสองที่: **Google Cloud** กับ **Supabase**
หน้าตาเมนูของ Google อาจต่างจากที่เขียนเล็กน้อย เพราะ Google เปลี่ยนหน้าบ่อย ชื่อปุ่มหลักๆ ยังเหมือนเดิม

> ไฟล์นี้อยู่ใน repo สาธารณะ — **ห้ามจด Client Secret ลงไฟล์นี้หรือไฟล์ไหนใน repo**

---

## ขั้น 0 · หา "Callback URL" ของ Supabase ก่อน

Supabase → **Authentication** → **Sign In / Providers** → เลื่อนลงไปที่ **Google** → กดเปิด
ในหน้านั้นมีช่อง **Callback URL (for OAuth)** หน้าตาประมาณ `https://xxxx.supabase.co/auth/v1/callback`
→ กดก๊อปเก็บไว้ (ยังไม่ต้องกด Save)

## ขั้น 1 · Google Cloud: สร้างโปรเจกต์

1. เข้า **console.cloud.google.com** ด้วยบัญชีที่จะดูแลระบบ (แนะนำ Gmail ที่ใช้เป็นหัวหน้าภาค)
2. มุมซ้ายบน กดเลือกโปรเจกต์ → **New Project** → ชื่อ `Prostho Tracker` → **Create**
3. รอสร้างเสร็จ แล้วเลือกโปรเจกต์นั้นให้เป็นโปรเจกต์ปัจจุบัน

## ขั้น 2 · Google Cloud: หน้ายินยอม (OAuth consent screen)

1. เมนู ☰ → **APIs & Services** → **OAuth consent screen** (บางรุ่นชื่อ **Google Auth Platform**) → **Get started**
2. **App name**: `Prostho Tracker` · **User support email**: อีเมลของคุณ → Next
3. **Audience**: เลือก **External** → Next
   (Internal ใช้ได้เฉพาะโปรเจกต์ที่อยู่ในองค์กร mahidol.edu — ถ้าสร้างด้วย Gmail จะเลือกไม่ได้ ไม่เป็นไร)
4. **Contact information**: อีเมลของคุณ → Next → ติ๊กยอมรับ → **Create**
5. ไปที่ **Audience** อีกครั้ง → กด **Publish app** → Confirm
   ⚠️ ถ้าไม่กด จะอยู่ในสถานะ Testing = เข้าได้เฉพาะอีเมลที่เพิ่มเป็น test user เท่านั้น
   (แอปนี้ขอแค่อีเมลกับชื่อ — Google ไม่ต้องตรวจสอบแอปก่อน publish)

## ขั้น 3 · Google Cloud: สร้างกุญแจ (OAuth client)

1. **Clients** (หรือ **Credentials** → **Create credentials** → **OAuth client ID**)
2. **Application type**: **Web application** · ชื่อ: `Supabase`
3. **Authorized redirect URIs** → **Add URI** → วาง **Callback URL จากขั้น 0**
4. **Create** → จะได้ **Client ID** กับ **Client Secret** → ก๊อปทั้งสองค่าไว้
   (Secret เก็บในที่ปลอดภัย เช่น Notes ที่ล็อกไว้ ห้ามส่งในแชทกลุ่ม)

## ขั้น 4 · Supabase: เปิดผู้ให้บริการ Google

Supabase → **Authentication** → **Sign In / Providers** → **Google**
1. เปิดสวิตช์ **Enable Sign in with Google**
2. วาง **Client ID** และ **Client Secret**
3. **Save**

## ขั้น 5 · Supabase: บอกว่าแอปอยู่ที่ไหน (สำคัญ)

Supabase → **Authentication** → **URL Configuration**
- **Redirect URLs** → **Add URL** → ใส่ที่อยู่ของแอปทุกที่ที่จะเปิดใช้ ต่อท้ายด้วย `/**` เช่น
  - ลองในเครื่อง: `http://localhost:5173/**`
  - เว็บจริง (เมื่อมี): `https://ที่อยู่เว็บจริง/**`
- **Site URL**: ใส่ที่อยู่เว็บจริง (ถ้ายังไม่มี ใส่ `http://localhost:5173` ไปก่อน)

ถ้าไม่ใส่ขั้นนี้ กลับจาก Google แล้วจะเด้งไปผิดที่ (มักไปหน้า Site URL แทนแอป)

## ขั้น 6 · ลอง

1. เปิดแอป → **เข้าสู่ระบบด้วย Google** → เลือกบัญชีที่อยู่ในรายชื่อเชิญ (เช่น Gmail ที่เป็นหัวหน้าภาค)
2. ควรกลับมาที่แอปและเข้าหน้าตามบทบาททันที
3. ลองอีกครั้งด้วยบัญชีที่**ไม่**อยู่ในรายชื่อ → ต้องขึ้นข้อความ "อีเมลนี้ยังไม่อยู่ในรายชื่อที่ภาควิชาเชิญ"
4. ลองบนมือถือจริง: iPhone (Safari) · Android (Chrome) · และ**ถ้ามีคนติดตั้งแอปลงหน้าจอโฮม ลองแบบนั้นด้วย**
   (ตรงนี้เทสต์อัตโนมัติทำไม่ได้ — ถ้ากลับจาก Google แล้วไปโผล่ใน Safari แทนในแอป ให้แคปหน้าจอส่งมา)

## ถ้าไม่ได้ผล

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| กดปุ่มแล้วขึ้น "ยังไม่ได้เปิดการเข้าด้วย Google บนเซิร์ฟเวอร์" | ขั้น 4 ยังไม่ Save |
| หน้า Google ขึ้น `redirect_uri_mismatch` | Callback URL ในขั้น 3 ไม่ตรงกับขั้น 0 (ต้องตรงทุกตัวอักษร) |
| หน้า Google ขึ้น "Access blocked" / เข้าได้แค่บางคน | ขั้น 2 ข้อ 5 ยังไม่ Publish |
| กลับมาแล้วไปโผล่หน้าอื่น ไม่ใช่แอป | ขั้น 5 ยังไม่ใส่ Redirect URLs ของที่อยู่นั้น |
| ขึ้น "อีเมลนี้ยังไม่อยู่ในรายชื่อที่ภาควิชาเชิญ" ทั้งที่ควรเข้าได้ | เลือกบัญชี Google ผิดอัน หรืออีเมลในรายชื่อเชิญสะกดต่างกัน — เช็คในหน้า "รายชื่อ & นำเข้า" |

## ความปลอดภัย · สิ่งที่ไม่เปลี่ยน
- ใครเข้าได้ยังตัดสินที่ฐานข้อมูลเหมือนเดิม (trigger `handle_new_user` ใน `0009`) — Google แค่ยืนยันว่าเป็นเจ้าของอีเมลจริง
- การล็อกอินด้วยอีเมล+รหัสผ่านยังใช้ได้ (บัญชีสาธิต/สำรอง) · ถ้าวันหน้าทุกคนใช้ Google แล้ว ปิดได้ที่ Sign In / Providers → Email
- บัญชีที่เคยสมัครด้วยรหัสผ่าน แล้วมาเข้าด้วย Google อีเมลเดียวกัน Supabase ผูกเป็นบัญชีเดียวกันให้เอง
